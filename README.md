

# 🏡 House Design  

## 📌 Overview  
**House Design** is a website dedicated to showcasing innovative and stylish home design ideas. It provides inspiration for modern, classic, and custom home designs, featuring architecture, interior decor, and space optimization tips.

## ✨ Features  
- Explore modern, classic, and custom home designs  
- Get interior decor and space optimization tips  
- Browse architecture inspiration for different styles  
- Interactive UI with a smooth user experience  
- Integration with Stripe for payments (if applicable)  

## ⚙️ Installation  
Follow these steps to set up the project locally:  

1. **Clone the Repository:**  
   ```sh
   git clone <repository-url>
   cd house-design
   ```  
2. **Install Dependencies:**  
   ```sh
   npm install
   ```  
3. **Run the Development Server:**  
   ```sh
   npm start
   ```  

## 🚀 Usage  
- Visit `http://localhost:3000` to explore home designs.  
- Browse different design categories and get inspiration.  
- Use search filters to find specific home styles.  
- If payments are involved, follow Stripe integration for checkout.  

## 📦 Dependencies  
This project uses the following packages:  
- **UI & Styling:** `daisyui`, `react-icons`, `sweetalert2`, `react-spinners`  
- **State Management & API Calls:** `@tanstack/react-query`, `axios`  
- **Routing & Navigation:** `react-router-dom`  
- **Animation:** `lottie-react`  
- **Printing & SEO:** `react-to-print`, `react-helmet-async`  
- **Authentication & Backend:** `firebase`  
- **Payment Integration:** `@stripe/react-stripe-js`, `@stripe/stripe-js`  

## 🔧 Configuration  
- If using Firebase, update your Firebase configuration in `.env` or a config file.  
- If using Stripe, set up Stripe public and secret keys in the environment variables.
